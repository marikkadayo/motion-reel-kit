# motion-reel-kit

話している縦動画1本から、手書き文字・カード・小窓・回るスクショ入りのリールを作る、Claude用のスキルです。

セリフに合わせて、次の演出が入ります。

- 冒頭: 過去の投稿のスクショと3段タイトル
- クレヨンで書かれていく手書き文字
- ラベル付きの写真がフォルダに入っていく動き
- 星つきの手書きリスト
- マインドマップ
- 白いカード3種（無音カット／字幕／話す速さ）
- 白い画面の小窓
- 最後: 手書きの締め文字と、回るスクショ

## 入れ方

1. このページの `motion-reel-kit.zip` を開き、「Download raw file」でダウンロードします（解凍しません）。
2. Claude の設定で「コード実行とファイル作成」をオンにします。
3. Claude の「カスタマイズ」→「スキル」→「＋」→「スキルを作成」→「スキルをアップロード」で、ZIP を選びます。
4. 一覧に motion-reel-kit が出て、オンになっていれば完了です。

## 使い方

チャットに動画と素材を添付して、次のように頼みます。

```
motion-reel-kit でリールを作ってください。
【動画】添付の縦動画
【台本】（撮ったセリフを順番に）
【過去の投稿のスクショ】添付の5枚
【素材の写真】添付の3枚（ファッション／ごはん／ファッション）
【手書きで出す文字】自分の名前
```

用意するもの、台本の型、直しの頼み方は、Substack「SNS部 byまりっか」の記事にまとめています。
https://snsbu.substack.com/

## 中身

- `motion-reel-kit/SKILL.md` — Claude が読む手順書
- `motion-reel-kit/scripts/reel_kit.py` — 動画を書き出すプログラム（Python・ffmpeg）

効果音のファイルは入っていません。素材を渡さない場合は仮の合成音になります。
